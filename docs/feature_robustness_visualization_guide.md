# 特征空间鲁棒性可视化指南

## 核心概念

### 什么是特征鲁棒性？

**好的特征**应该能够：
- 在不同数据风格（亮度、对比度、噪声）下保持稳定
- 将同一物体的不同变体映射到特征空间中的相近位置
- **弥合不同测试集间的差异**

### 如何可视化？

在同一个特征空间中：
- **不同颜色** = 不同风格的数据（原始、亮、暗、噪声、高对比度）
- **聚在一起** = 特征对风格变化鲁棒 ✓
- **分散开** = 特征受风格影响大 ✗

## 参数说明

```bash
python scripts/visualization/visualize_feature_robustness.py [选项]
```

### 参数

- `--output`, `-o`：输出图表路径
  - 默认：`outputs/figures/feature_robustness.png`

- `--digit`：要可视化的数字类别
  - 默认：`8`（数字8）
  - 范围：0-9
  - 建议：选择特征明显的数字（0、1、8）

- `--samples`：每种风格的样本数
  - 默认：`200`
  - 建议：100-300

## 结果解读

### 图表布局

```
[原始像素特征空间]  [HOG特征空间]  [HU矩特征空间]
   不同风格分散      不同风格聚集     不同风格聚集
      距离大            距离小          距离小
     鲁棒性差         鲁棒性好        鲁棒性好
```

### 评价指标

**风格中心平均距离**：
- 计算每种风格在特征空间中的中心
- 计算这些中心到总体中心的平均距离
- **距离越小** → 不同风格越聚集 → **鲁棒性越好**

### 预期结果

#### HOG 特征（最佳）

```
  亮 ●●    原始 ■■
暗 ●● ●● ■■ ■■
  ●● ■■ ■■    噪声 ▲▲
    ■■ ▲▲ ▲▲
      ▲▲ ▲▲
```

**特点**：
- ✅ 不同风格聚在一起
- ✅ 风格中心距离小
- ✅ 梯度方向对亮度不敏感

#### 原始像素（较差）

```
亮 ●●●●
    
原始 ■■■■
        
暗       ▲▲▲▲
```

**特点**：
- ✗ 不同风格分散
- ✗ 风格中心距离大
- ✗ 像素值直接受亮度影响

#### HU 矩（中等）

```
  ●●■■▲▲
  ●●■■▲▲
```

**特点**：
- ✓ 形状不变性好
- ✗ 信息损失多（只有7维）
- ~ 聚类效果取决于形状复杂度

## 与其他可视化的区别

### vs. 聚类可视化（之前的脚本）

| 方面 | 特征鲁棒性可视化 | 聚类可视化 |
|------|------------------|------------|
| 目标 | 测试特征对风格的鲁棒性 | 展示特征的区分能力 |
| 颜色 | 不同风格 | 不同类别 |
| 关注点 | 同一类别的不同风格是否聚集 | 不同类别是否分离 |
| 评价 | 风格中心距离 | 类别分离度 |

### 互补关系

1. **聚类可视化**：告诉你特征能否区分不同类别
2. **鲁棒性可视化**：告诉你特征能否抵抗风格变化

**两者结合**：
- 好特征 = 类别分离 + 风格鲁棒
- HOG 在两方面都表现优秀

## 技术细节

### 为什么用 PCA 降维？

- **速度快**：适合快速探索
- **保持全局结构**：能看到整体分布
- **确定性**：每次结果相同
- **可解释**：主成分有明确含义

### 特征维度

- 原始像素：28×28 = **784** 维
- HOG（ppc=4×4）：约 **1764** 维
- HU矩：**7** 维

### 计算复杂度

```
时间 = O(n_samples × n_styles × feature_dim)

典型：200 × 5 × 1764 ≈ 1.76M 操作
预计：< 30 秒（PCA）
```

## 常见问题

### Q1: 为什么只用一个数字类别？

**A**: 
- 避免不同类别混淆视觉
- 专注于观察**同一物体**在不同风格下的表现
- 如果要看类别分离，请用聚类可视化

### Q2: 风格中心距离多少算好？

**A**:
- 没有绝对标准，**相对比较**更重要
- HOG < 原始像素 → HOG 更鲁棒
- 典型值：HOG (10-20), 原始 (30-50)

### Q3: 为什么 HU 矩有时表现不稳定？

**A**:
- 只有 7 维，信息量有限
- 依赖形状，对复杂数字效果差
- 二值化过程可能损失信息

### Q4: 如何选择要可视化的数字？

**A**:
- **推荐**：8（形状明显，两个圆）
- **备选**：0（圆形）、1（竖线）、3（复杂形状）
- **避免**：6和9（容易混淆）
